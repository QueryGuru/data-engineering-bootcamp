# Data Engineering Bootcamp

This repository contains production-style data pipelines built to demonstrate
end-to-end data engineering skills including ingestion, transformation,
orchestration, and data quality.

## Architecture (High Level)
Source APIs → Bronze (Raw) → Silver (Validated) → Gold (Analytics)

## Goals
- Idempotent pipelines
- Incremental processing
- Analytics-ready data models
- Production-grade reliability

More details in /docs.
